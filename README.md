# autosea

This is a script for completing a softcore ascension in the 11037 Leagues Under the Sea challenge path from Fall 2025. It only works for accordion thief and assumes access to most of the iotms/iotys from 2023 to 2025. Resources are not conserved very optimally for looping, as much of the logic was originally developed for speedrunning the path. Hopefully it serves as a useful starting point for more useful and generalizable efforts in this area.

## Requirements

For the script to succeed out of the box, you likely need almost every iotm/ioty from 2023 to 2025, except for the following:

* Candy cand sword cane
* Hobeep
* Mini kiwi

A lot of this is due to hardcoded itemization in most tasks. I also equip the designer sweatpants.

There are also many skill requirements, too many for me to want to list all of them.

Finally, without access to PYEC or unaccompanied miner, you are unlikely to complete all mining before running out of charges of Loded. In this case, the script will currently abort and request you to manually mine the teflon ore.

## Expectations

I would expect autosea to ascend in softcore in about 60-70 turns, while using all of your free kills, steely-eyed squint, habs, and a bunch of pulled/purchased freeruns (this is the first thing I would probably remove resource-consumption wise).

At the moment, I'm not maintaining this script.
